# Kobo — galeria de demonstração

[Comparar as quatro interfaces](https://monkeyprogramer123.github.io/Public/)

Este repositório público contém **apenas recursos estáticos e dados sintéticos**:
quatro interfaces (Equilibrada, Minimalista, Agenda e Editorial), nas edições de
manhã e fim do dia. Os oito PNGs têm exatamente 1448 × 1072 píxeis.

Não contém calendários pessoais, previsões ou notícias reais, credenciais, código
do servidor privado nem imagens obtidas do Kobo. Uma prévia não comprova a
apresentação física no dispositivo.

As imagens são reconstruídas e comparadas byte a byte com os modelos sintéticos
antes da publicação. A atualização usa commits normais, preservando o histórico.
GitHub Pages publica a raiz da branch main; .nojekyll mantém os recursos estáticos.

A fonte Atkinson Hyperlegible é distribuída sob SIL OFL 1.1; consulte
[fonts/OFL.txt](fonts/OFL.txt). Copyright 2020 Braille Institute of America, Inc.
